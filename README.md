# DL Performance Marketing

Static marketing site for **DL Performance Marketing LLC**.

- Brand site for Meta ads / DTC performance marketing
- Address: 1021 E Lincolnway Suite 9813, Cheyenne, WY 82001
- Deployed on Render as a static site

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Deploy

Push to GitHub, then create a Render Static Site with:

- **Build command:** `echo ok` (or leave as a no-op)
- **Publish directory:** `.`
